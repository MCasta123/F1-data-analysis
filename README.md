# F1 Data Analytics 

Questo progetto nasce con l'obiettivo di creare un sistema integrato per l'estrazione e l'analisi dei dati della Formula 1.

### Funzionalità

Una volta scelto l'anno, la gara e la specifica sessione di interesse (fp1,fp2,fp3,qualifiche,qualifiche sprint, gara sprint, gara) è possibile:

-Stampare tutti i giri di un determinato pilota

-Stampare i risultati deell sessione

-Stampare una classifica dei piloti ordinati per giro veloce

### Requisiti

Dipendenze Python 

Libreria fastf1

Libreria pandas

Libreria matplotlib

Installabili con:

**pip install pandas fastf1 matplotlib**
